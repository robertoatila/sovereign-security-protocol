# Security policy / Política de segurança

## Scope

This repository publishes documentation and control guidance. It is not an executable security product. A flaw in a requirement, mapping, example, or public artifact can still mislead adopters and should be reported responsibly.

## Reporting a vulnerability or material security issue

- Prefer the hosting platform's private vulnerability-reporting/advisory feature when available.
- If that feature is unavailable, use a maintainer contact method published on the hosting profile. Do not post exploit details, credentials, personal data, or private runtime findings in a public issue.
- Include the affected file and revision, impact, reproduction or supporting evidence, and a safe disclosure preference. Redact secrets and unrelated user data.
- The maintainers will acknowledge and coordinate a response when a contact path is available. This draft does not promise a response-time SLA.

For issues in the originating SSP source, report to its [originating repository](https://github.com/robertoatila/jarvis-skill-registry) under that project's current disclosure policy. Do not infer that this community edition speaks for the upstream maintainers.

## Supported edition

The current content is **Community Edition 0.1.0 (draft)**, based on SSP v13.4.0. A later edition may clarify or supersede it. The source protocol remains governed by its origin repository.

## Português

### Escopo

Este repositório publica documentação e orientação de controles, não um produto executável. Uma falha em requisito, mapeamento, exemplo ou artefato público pode orientar adoção incorreta e deve ser relatada de forma responsável.

### Relato de vulnerabilidade ou problema material

- Prefira o recurso privado de relato/aviso de segurança da plataforma quando disponível.
- Se não existir, use um contato de mantenedor publicado no perfil de hospedagem. Não publique detalhes de exploração, credenciais, dados pessoais ou achados privados de runtime em issue pública.
- Inclua arquivo e revisão afetados, impacto, reprodução/evidência e preferência de divulgação segura. Redija segredos e dados de usuário sem relação.
- Os mantenedores coordenarão a resposta quando houver um canal de contato. Este draft não promete SLA.

Para problemas na fonte SSP, reporte no [repositório de origem](https://github.com/robertoatila/jarvis-skill-registry), conforme a política de divulgação vigente daquele projeto. Esta edição comunitária não representa seus mantenedores.

### Edição apoiada

O conteúdo atual é **Community Edition 0.1.0 (draft)**, com base na SSP v13.4.0. Uma edição futura pode esclarecer ou sucedê-la. O protocolo de origem continua governado no seu repositório.
