# Roadmap / Roteiro

This roadmap is a proposal for the community edition. It does not commit the upstream protocol maintainers or promise a release date.

Este roteiro é uma proposta para a edição comunitária. Não compromete os mantenedores do protocolo upstream nem promete data de release.

## Draft 0.1 — current / atual

- Bilingual protocol, adoption and evidence guides.
- 13-control crosswalk to the source v13.4 domains.
- Agentic AI/MCP and J.A.R.V.I.S./Obsidian profile.
- Provenance, official-source map, and community governance.
- Static Obsidian navigation and Canvas; no private vault data.

## Candidate priorities / Prioridades candidatas

1. Invite independent security reviewers to challenge control wording and applicability.
2. Review each crosswalk range against the exact source text and add narrower section links where they help.
3. Gather non-sensitive implementation examples contributed by adopters, each labeled by evidence level and system context.
4. Review EN/PT-BR parity with maintainers who work in both languages.
5. Recheck standards and protocol references before any tagged edition.
6. Consider machine-readable control data only after the control schema, ownership, and change process are agreed.

The project values verified usefulness and healthy maintenance over a star target. No number of adopters, certifications, or security outcomes is promised.
